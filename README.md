# Информационная система «Распределение дополнительных обязанностей кафедры»

Приложение на PyQt5 для распределения дополнительных работ между сотрудниками кафедры. Позволяет заведующему кафедрой создавать работы, назначать исполнителей и вести историю, а исполнителям — оценивать трудоёмкость работ и отмечать их выполнение.

## Развёртывание

Перед началом установки на компьютере должны быть установлены:
- **Python 3.13**
- **PostgreSQL**
- **Git**

### 1. Клонирование репозитория

```bash
git clone https://github.com/egoand/Kurs
```


### 2. Установка библиотек

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка PostgreSQL

Создайте базу данных `pis_db`:

```bash
psql -U postgres -c "CREATE DATABASE pis_db;"
```

При запросе введите пароль пользователя `postgres`, который вы задали при установке PostgreSQL (у меня - 1).

Выполните SQL-скрипт из файла `init.sql`. Скрипт создаёт таблицы и наполняет их тестовыми данными:

```bash
psql -U postgres -d pis_db -f init.sql
```

### 4. Настройка подключения

Откройте файл `db.py` и проверьте параметры подключения:

```python
CONN = dict(
    host='localhost',
    port=5432,
    dbname='pis_db',
    user='postgres',
    password='1', # нужно заменить на пароль, заданный при установке PostgreSQL
    client_encoding='UTF8'
)
```

### 5. Запуск приложения

```bash
python main.py
```
